# Stage 02: Roles

> **The question this stage answers:** Which GenAI roles exist, which are the best, and which should I target?
> **Status:** Covered: reference documents, the role map and one hub per role exist. Overall progress is tracked in [ROADMAP.md](../../ROADMAP.md).

## In this folder

Read in three steps: start with the target order and the role hubs, explore with the role map and the emerging-roles guide, then check the evidence in the catalog and the rankings.

| Step | Document | What it gives you |
|---|---|---|
| 1 Start | [genai-target-roles.md](genai-target-roles.md) | Which roles to target, in order: the GenAI-only target order (a consensus of eight lenses), the tier rules, one line per role, and how to choose one cluster, its top title and two adjacent titles |
| 1 Start | [hubs/](hubs/README.md) | One generated page per role: definition, footprint, graded scores, who it suits, skills, proof, interview track and résumé pointers, with links to the evidence |
| 2 Explore | [role-map.md](role-map.md) | Where each role's work sits: six stack layers from compute to applications, four cross-cutting planes, every role's footprint, the specialisations inside roles, and how to choose a direction (generated) |
| 2 Explore | [emerging-roles.md](../01-landscape/emerging-roles.md) (in stage 01) | How to judge a new title: the graduation tests in plain words, a dated watchlist, and how to use emerging terms honestly |
| 3 Evidence | [role-catalog.md](role-catalog.md) | All 29 canonical roles and 241 classified titles: profiles, evidence status, aliases, the quarantine and not-a-role registers, A–Z index |
| 3 Evidence | [role-rankings.md](role-rankings.md) | The Composite Career Index on all demand: pillar scores with uncertainty ranges, Monte Carlo, weight sensitivity, persona and India lenses, per-role dossiers |

**Two rank systems.** [GenAI target roles](genai-target-roles.md) ranks GenAI work only and puts AI Engineer first; the [role rankings](role-rankings.md) score all demand for each title and put ML Engineer first. Choose targets with the first, and judge a role as a whole career with the second.
