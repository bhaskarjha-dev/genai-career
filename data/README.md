# Data: Machine-Readable Sources of Truth

The documents in [career/](../career/README.md) that show scores, skills, titles, projects, prompts, tools or findings are generated from these files by [scripts/](../scripts/README.md). Edit the data, then run `python3 -B scripts/build_all.py`; never hand-edit generated output. Each fact has one owner (decision D-019): if a page needs a fact that lives here, it links or generates it rather than copying it.

| File | What it holds | Edited by | Read by |
|---|---|---|---|
| [role_scores.json](role_scores.json) | Every role's definition, work footprint (layers and planes), interview track and pillar scores (demand, pay, durability, leverage, access) as [lo, mid, hi] ranges with evidence grades and sourced bases; the GenAI-restricted demand ranges that the target order uses; the interview tracks; the track playbooks written for particular roles | Hand | `rank_roles.py`, `target_roles.py`, `build_role_map.py`, `build_role_hubs.py`, `build_prompts.py`, `build_index.py` (role ids), `stack_lib.py`, `validate_docs.py` |
| [role_titles.json](role_titles.json) | Every posting title the role catalog classifies: index type, the canonical role it maps to, evidence or note | Hand | `build_index.py` (the A–Z index in the role catalog) |
| [stack_model.json](stack_model.json) | The stack map (decision D-015): six layers, four cross-cutting planes, the map from skill categories to layers, and the specialisations inside roles | Hand | `stack_lib.py`, `build_role_map.py`, `build_role_hubs.py`, `build_archetypes.py` |
| [skills_ontology.json](skills_ontology.json) | Typed skills, choose-one classes, credentials, résumé variants with per-variant headlines, every role's tiered and evidence-tagged skill links, the register of devalued skills, verification notes | Hand; each role's `target` is written by `target_roles.py` | `build_skills.py`, `build_resume_matrix.py`, `resume_layers.py`, `build_skills_views.py`, `build_archetypes.py`, `build_role_map.py`, `build_role_hubs.py`, `build_prompts.py`, `gap_analysis.py`, `validate_docs.py` |
| [posting_skill_shares.json](posting_skill_shares.json) | Dated snapshots of the skills job postings name, by posting title (JobsPipe, retrieved 2026-11-02, Grade B) | Hand (a new snapshot is added, never edited) | `build_skills.py` (checks every JD share in the ontology against it, and renders it in role-skill-inventories), `build_skills_views.py` |
| [project_archetypes.json](project_archetypes.json) | The proof-of-work project archetypes: problem, build steps, evidence to publish, verifiability target, effort, compute, interview archetypes, pitfalls, sources and the headline skills each one evidences | Hand | `build_archetypes.py`, `resume_layers.py`, `build_role_map.py`, `build_role_hubs.py`, `gap_analysis.py` |
| [interview_prompts.json](interview_prompts.json) | Practice prompts keyed to interview tracks, the system-design archetypes, roles and skills, with what a strong answer covers, red flags and session sources | Hand | `build_prompts.py`, `build_archetypes.py` |
| [tools.json](tools.json) | External career tools and platforms by stage, with verdict, evidence grade, session source and date | Hand | `build_tool_catalog.py` |
| [findings.json](findings.json) | The key findings of the research sessions, with grade, exact line and lifecycle stages | Generated by `build_findings.py` | Agents and tools (the same records are in [research/findings.md](../research/findings.md)) |
| [manifest.json](manifest.json) | Every document's front matter and section headings | Generated by `build_manifest.py` | Agents and tools (the same index is in [llms.txt](../llms.txt)) |
| [schemas/](schemas/) | JSON Schemas for every hand-edited data file and for document front matter, in the subset `scripts/common.py` implements (it rejects any keyword it does not enforce) | Hand | The generators that read each file, `validate_docs.py`, `scripts/tests/` |
