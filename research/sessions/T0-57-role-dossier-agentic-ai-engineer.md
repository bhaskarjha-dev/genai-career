## Research Question

**Decision question:** what should the knowledge base say about the Agentic AI Engineer role (definition, demand, pay, skills, proof, credentials, interviews, careers, geography), and should the title graduate from watchlist status?

**Sub-questions:** (1) Is it a distinct title or an alias? (2) How large is demand at title level, and what is the trend? (3) What do postings ask for, by employer type and region? (4) What do postings, filings and platforms show for pay? (5) How are candidates interviewed, and with what AI-tool policy? (6) What is different in India?

**Reading chosen:** I classified each posting by what it asks for (building tool-using, multi-step LLM agents in production). Platform, forward-deployed and customer-facing variants count as variants of the role. Architect-only, governance, sales and "agent experience" (agent-discovery optimisation) roles do not.

**Method (all on 2026-11-13):**
- About 35 web searches and 8 page fetches. Searches covered ATS-targeted title queries (Greenhouse, Ashby, Workday), Big Tech and enterprise-vendor employers (Amazon, Microsoft, Salesforce, ServiceNow, SAP), frontier-model employers (OpenAI, Anthropic, Cohere), India (Capgemini, Wipro, Goldman Sachs, others), Europe, AI-native startups, pay (Levels.fyi, India self-report sites), AWS AIP-C01, LCA trackers, AutoGen status, title-level demand (IT Jobs Watch, Skilark, Lightcast), interviews (Sierra, candidate-report aggregators) and proof-of-work sources.
- Fetches: the Ai2 posting and board (full); GT's Ashby page (metadata only); Goldman Sachs (empty shell); an Amazon posting on a mirror board (full); Wipro (page reported as not available); Sierra's interview post (full); one aggregator API snapshot dated 2026-05-19, used only for Cleric's interview text.
- **Sampling bias:** the search index over-represents aggregators and mirror boards. The dated mirrors (anitab.org, purpose.jobs, thrivecap.com, omegavp.com, Getro boards) favour Big Tech, enterprise vendors and VC-backed startups, so my US sample under-represents US exact-title postings found elsewhere (Zeta Global, Benchling and SAP, all older or undated). Ashby, Workday and Goldman pages are JavaScript-rendered and returned no body to fetch. Greenhouse, Lever and Ashby pages print no posting date, and a mirror's "posted" date can be a repost date.
- **Exclusions (what and why):** about 15 anonymised or employer-less aggregator listings (no board URL); 3 near-duplicate ServiceNow listings, 3 further Salesforce listings (used for pay only) and 3 further Amazon listings (employer cap of three per employer); AgentMail's "Agent Experience Engineer" (optimises how agents discover a product; not this role; dated 2026-08-10); Capgemini architect, governance and leader roles; Wordware and Console roles dated before the window. No robotics or low-code jobs surfaced.
- **Falsification searches:** the exact title at frontier labs and Big Tech (none found; the work is titled Software Engineer, SDE or Applied AI Engineer); the exact title in LCA filings (none; the alias "Agent Engineer" found); "alias, not title" (Lightcast supports it, one vendor survey contradicts it); keyword counts against title counts; AutoGen "dormant" (maintenance mode confirmed, yet still named in postings).

## Recommendation

1. **Search by alias cluster, tuned by region.** In India and Europe search the exact title. In the US search "Software Engineer, Agent(s)", "AI Agent Engineer", "Applied AI Engineer" and team names containing "Agentic AI". *Failure mode:* "AI Agent Engineer" can be customer-facing (ServiceNow Moveworks asks for 5+ years in a customer-facing role); read the first responsibilities.
2. **Plan for mid-to-senior entry.** Most postings ask 4–8+ years of software engineering. Backend and full-stack engineers should apply directly; graduates should target graduate programmes and junior-titled roles. *Failure mode:* the graduate evidence is thin (three postings, one of them adjacent).
3. **Build proof around evals and a shipped agent.** An agent with tool use, a sandbox, an eval suite, cost per task and a written failure story; be ready to explain how you used AI tools to build it. *Failure mode:* trace replay and failure injection are practice-curated (P), not employer-stated; AI-tool policies differ by employer.
4. **Lead with agents, tool use, orchestration, evals and reliability; name frameworks as the posting does.** Add MCP when targeting Amazon, Microsoft, SAP or similar. Do not headline AutoGen or CrewAI. *Failure mode:* n = 14; shares may move at n ≥ 30.
5. **Skip certifications unless targeting Indian services employers.** Azure AI-series certificates are named more often than AIP-C01. *Failure mode:* one older Indian posting called a certification mandatory.
6. **In India, anchor on posted bands by employer type, not on Glassdoor's small-sample averages.** *Failure mode:* posted bands are few and may not equal what is paid.
7. **Treat sponsorship as employer-specific.** LCAs exist for alias titles; check each posting's work-authorisation text. *Failure mode:* filing wages are not pay.

**What would change this advice:** a verified sample of 30+ postings with a printed date; a title-only counts series (Skillenai or JobsPipe); an LCA filing under the exact title; a frontier-lab posting using the exact title; employer-published loop descriptions for agent roles beyond Sierra.

## Detailed Findings

### D1. Definition, variants and aliases

**Definition at 2026-11-13.** Engineers who build and run LLM agents that use tools across multiple steps, with the surrounding harness: orchestration, memory and context, evaluation, guardrails and observability. Postings describe multi-agent orchestration, memory and failure recovery (ServiceNow), the agent harness, tools and infrastructure behind OpenAI's models (OpenAI API Agents), the runtime, memory and tool gateway of an agent service (Amazon), and agent platform runtime, traces and evaluation tooling (Ai2) [S1, S7, S8, S11]. Durable execution, state machines and human approvals (the KB's wording) are rarely named in the sample.

**Variants by employer type:** platform or harness builder (Ai2, OpenAI, ServiceNow harness); product agent engineer (Salesforce Agentforce, Amazon, Microsoft, CUBE, APAS, Juro); forward-deployed (ServiceNow Moveworks, Sierra, Simple AI); enterprise and IT-services delivery (Capgemini, Wipro, EPAM, Opsfleet); software-delivery-lifecycle agents (Workday). **Adjacent roles:** AI Engineer (generalist), ML Engineer, forward-deployed engineer, AI architect, low-code automation engineer.
